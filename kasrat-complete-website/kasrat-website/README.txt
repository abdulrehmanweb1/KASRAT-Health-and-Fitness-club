KASRAT HEALTH & FITNESS CLUB — COMPLETE WEBSITE PROJECT

This ZIP contains the complete editable static website source.

PAGES
- index.html       Home
- about.html       About Kasrat
- facilities.html  Facilities & training
- gallery.html     Gallery with image lightbox
- contact.html     Contact and two branch locations

PROJECT ASSETS
- css/style.css             Shared responsive styles and animations
- js/script.js              Mobile navigation, reveal animations, gallery lightbox
- assets/kasrat-logo.jpg    Logo cropped from the logo image supplied in chat
- assets/owner-fazeel.jpg   Existing owner photo asset
- assets/owner-video.mp4    Existing owner video asset
- assets/gym-photos/        Folder reserved for official gym photographs

FEATURES
- Responsive navigation and mobile menu
- Shared header and footer on all pages
- Kasrat logo and social media icons/links
- Fitness imagery in Facilities and Gallery
- Gallery lightbox
- WhatsApp, telephone, membership form, and Google Maps links
- CSS motion/reveal effects and reduced-motion support

RUN LOCALLY
1. Extract this ZIP.
2. Open the kasrat-website folder in VS Code.
3. Use the Live Server extension and open index.html.
4. Navigate through all five pages and test links on mobile and desktop.

DEPLOY TO VERCEL
1. Import/upload the extracted project folder to a Vercel static project.
2. Keep index.html in the project root; no build command is required for this static HTML project.
